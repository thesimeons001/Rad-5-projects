# My First Express Server

A simple backend server built with Node.js, Express.js, and TypeScript.

## Features
- Express server setup.
- TypeScript for type safety.
- GET route for the homepage.
- Server runs on port 3000.

## Project Structure

## Installation

```bash
npm install
```

## Compile TypeScript

```bash
npx tsc
```

## Run the Server

```bash
node dist/server.js
```
